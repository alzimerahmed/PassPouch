PassPouch database icon set ("PassPouch" style)

Generated for PassPouch by converting the vendored KeePassXC-derived icon set
(db-icons/keepassxc) into monochrome template silhouettes. The source icons are
the MIT-licensed assets already vendored in this repository (see
db-icons/keepassxc and its license attribution). The proprietary
"Round Icons / Bold Outline Icons" set previously used here was removed —
its license does not transfer to PassPouch.
